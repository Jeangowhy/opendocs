== Painter App Base on Web API

• https://github.com/linjc/smooth-signature
• https://linjc.github.io/smooth-signature/

目前 Web 平台还不能很好地支持压感笔绘画，特别是在手机端，还存在很大的设备兼容问题。一个可行的替代方案是以速度模变化拟压力变化。例如，开源的 smooth-signature 设置 minSpeed 参数来控制（映射）笔触最小宽度，最小速度取值范围 1.0-10.0 (px/ms)，值越小，画笔越容易变细。还设置 maxWidthDiffRate 参数控制相邻两线宽度增(减)量最大百分比，取值范围 1-100。为了达到笔锋效果，画笔宽度会随画笔速度而改变，如果相邻两线宽度差太大，过渡效果就会很突兀，通过限制宽度变化率，让过渡效果更自然。

此模块的实现步骤如下：

[source,ts]
----
interface IPoint {
  x: number;
  y: number;
  t: number;
  speed?: number;
  distance?: number;
  lineWidth?: number;
  color?: string;
}
----

• 采集定点设备运动事件（pointermove）产生的坐标，以及相应的时间数据。
• 根据相邻两点之间的座标和时间差数据计算移动速度。

[stem,role=big]
++++++
\begin{align}
distance &= \sqrt{(p_2.x - p_1.x)^2 + (p_2.y - p_1.y)^2}
\\ \\
    spee &= {distance \over (p_2.t - p_1.t)}
\end{align}
++++++

[source,ts]
----
const distance = Math.sqrt(Math.pow(p2.x - p1.x, 2) + Math.pow(p2.y - p1.y, 2));
const speed = distance / (p2.t - p1.t);
----

• 通过速度值模拟两点之间线的粗细变化，使用到 maxWidth、minWidth、minSpeed 配置项。

[stem,role=big]
++++++
\begin{align}
 addWidth &= {(W_{max} - W_{min}) \times speed \over Speed_{min}}
\\ \\
lineWidth &= \min(\max(W_{max} - addWidth, W_{min}), W_{max})
\end{align}
++++++

[source,ts]
----
const addWidth = (maxWidth - minWidth) * speed / minSpeed;
const lineWidth = Math.min(Math.max(maxWidth - addWidth, minWidth), maxWidth);
----

• 加入线条粗细变化速率约束条件防止相邻两条线宽度变化突兀，需要前一线条作为基准参考。

[stem,role=big]
++++++
\begin{align}
     rate &= {\text{lineWidth} - \text{preLineWidth} \over \text{preLineWidth}}
\\ \\
lineWidth &= \begin{cases}
    preLineWidth \times (1 + maxWidthDiffRate) \qquad \text{ if rate > 0, }
    \\ \\
    preLineWidth \times (1 - maxWidthDiffRate) \qquad \text{ if rate <= 0, }
    \end{cases}
\end{align}
++++++

[source,ts]
----
const rate = (lineWidth - preLineWidth) / preLineWidth;
const maxRate = maxWidthDiffRate / 100;
if (Math.abs(rate) > maxRate) {
    const per = rate > 0 ? maxRate : -maxRate;
    lineWidth = preLineWidth * (1 + per);
}
----

• 为了让线条看起来圆润以及线粗细过渡更自然，在两相邻点之间进行线性插值：线段平均成三段。为了让两端连接平滑，采用二次贝塞尔曲线绘制线条。第二段线（中部）使用梯形填充，让过渡效果更自然。

** 第一段 stem:[L_1 = (x_0,y_0) - (x_1,y_1)] 线宽设置为：stem:[W_1 = (preLineWidth + lineWidth) / 2]
** 第二段 stem:[L_2 = (x_1,y_1) - (x_2,y_2)] 保持前一步计算到的线宽。
** 第三段 stem:[(x_2,y_2) - (x_3, y_3)] 线宽设置为：stem:[W_3 = (nextLineWidth + lineWidth) / 2]
+
[source,ts]
----
ctx.lineWidth = lineWidth1
ctx.beginPath();
ctx.moveTo(pre_x, pre_y);
ctx.quadraticCurveTo(x0, y0, x1, y1);
ctx.stroke();
----

• 最后使用渲染专用 API 接口 requestAnimationFrame 以稳定时间帧执行画线函数。


定点设备（pointing device）是指通过 精确坐标定位 与计算机交互的硬件设备，所谓 pointing device 是指一个可以明确指向屏幕上某一组坐标的硬件设备。常见类型包括：

• 鼠标：通过 X/Y 轴移动和点击操作。
• 触控板/触摸屏：支持多点触控和手势操作。
• 压感笔（如 Wacom 数位板）：提供压力、倾斜度等高精度输入。
• 游戏手柄摇杆：通过模拟摇杆实现方向控制。

目前绝大多数的 Web 内容都假设用户的定点设备为鼠标，对应产生 mousedown，mousemove，mouseup，mouseover 等事件。然而，近年来的新兴设备支持更多不同方式的定点输入，如各类触控笔和触摸屏幕等。新的定点设备事件 Pointer events 是一类可以为定点设备所触发的 DOM 事件，通过 pointerType 属性判断设备类型。它们被用来创建一个可以有效掌握各类输入设备（鼠标、触控笔和单点或多点的手指触摸）的统一的 DOM 事件模型，支持压感笔（pressure）。对于非压感设备，浏览器会在 PointerEvent 中填充 0.5 的压力值。

PointerEvent 对应替代的 MouseEvent 和 TouchEvent 事件

[opts="autowidth"]
|===
|PointerEvent   |MouseEvent |TouchEvent

|pointerdown    |mousedown  |touchstart
|pointermove    |mousemove  |touchmove
|pointerup      |mouseup    |touchend
|pointerleave   |mouseleave |-
|pointercancel  |-          |touchcancel
|===

Chrome 浏览器在压感笔设置为 Windows Ink 模式下才有压力变化。压感笔设置为 Windows Ink 模式，需要避免在绘画是 Edge 平移页面。需要使用 touch-action: none 样式禁止触摸平移行为。事件捕获阶段（Capturing Phase）或 prevetDefanult() 无法解决 Edge 平移页面的行为。

压感笔的特殊处理

• 压力值（Pressure, 0~1）：通过 event.pressure 获取。
• 倾斜度（Tilt）：通过 event.tiltX 和 event.tiltY 获取

问题：Pointer Events 实现压感笔绘制粗细变化线条。由于 canvas 的通一条路径（beginPath 和 closePath 之间）会共用同样的笔刷大小，所以直接使用 DOM 事件驱动绘画时，后续的压力变化会影响前面的笔迹。并且，线条由细变粗后会遮盖细线条，除非清除画布重绘。解决办法是记录定点座标与压力信息，统一做数据处理。此外，根据设备像素比（DPR）缩放 Canvas 尺寸，使用 ctx.scale(dpr, dpr) 确保绘制精度。

浏览器兼容性与调试工具

• Chrome DevTools：通过 Sensors 面板模拟触控笔输入。
• Edge DevTools：使用 Pen Input 模拟压感笔事件。

技术方案关键建议：

• 优先使用 Pointer Events API 统一处理多设备输入。
• 在需要高精度时，结合 Windows Ink API 或 HID 协议 (实验性技术)。
• 始终进行设备兼容性测试（尤其是跨浏览器场景）。

USB HID（Human Interface Device）设备包括键盘、鼠标、触控板、游戏手柄、摇杆、工业控制设备、自定义外设等。用户授权要求：必须通过用户交互（如点击）触发设备请求。

|基础绘图       |Pointer Events + 压力值映射   |鼠标/触控板
|高精度压感绘图 |Windows Ink API + 压力反馈    |Wacom 数位板
|3D 建模        |WebGL + HID 协议             |专业工业设备

<script>

  const canvas = document.getElementById('drawingCanvas');
  const ctx = canvas.getContext("2d")
  const DPR = window.devicePixelRatio || 1;

  let g_drawing = false;
  
    function resizeCanvas() {
    const rect = canvas.getBoundingClientRect();

    canvas.width = rect.width * DPR;
    canvas.height = rect.height * DPR;
    
    ctx.scale(DPR, DPR);
  }

  resizeCanvas();
  window.addEventListener('resize', resizeCanvas);

  canvas.addEventListener('pointerdown', startDrawing);
  canvas.addEventListener('pointermove', draw);
  canvas.addEventListener('pointerup', stopDrawing);

  function startDrawing(e) {
    if (e.buttons !== 1) return // assume buttons 1 is left button
    const {pointerId, pointerType, buttons, tiltx, tilty} = e;
    console.log("startDrawing", 
                event, {pointerId, pointerType, buttons, tiltx, tilty});
    g_drawing = true;
    const { offsetX, offsetY } = e;
    ctx.beginPath();
    ctx.moveTo(offsetX, offsetY);
  }

  function draw(e) {
    const {pointerType, buttons, tiltx, tilty} = e;
    if (!g_drawing) return;
    const { offsetX, offsetY, pressure } = e; // pressure value [0, 1]
    ctx.lineWidth = pressure * 10;
    ctx.lineTo(offsetX, offsetY);
    ctx.stroke();
  }

  function stopDrawing(e) {
    g_drawing = false;
    console.log({pointerId : e.pointerId})
    canvas.releasePointerCapture(e.pointerId);
  }

</script>
